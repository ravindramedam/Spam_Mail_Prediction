# 📧 Spam Mail Prediction

Spam Mail Prediction is a **Machine Learning project** that classifies whether an email message is **Spam (junk)** or **Not Spam (ham)**.

The model is trained using **Logistic Regression**, a supervised learning algorithm commonly used for binary classification problems.  
It analyzes the text content of emails and predicts whether the message is spam or legitimate.

---

## 🎯 Objective

The goal of this project is to build a machine learning model that can automatically detect spam emails and help filter unwanted messages.

---

## ⚙️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn

---

## 🧠 Machine Learning Model

The project uses the **Logistic Regression algorithm** for spam classification.

Key steps include:

1. Data Collection  
2. Data Preprocessing  
3. Feature Extraction  
4. Train-Test Split  
5. Model Training using Logistic Regression  
6. Model Evaluation  
7. Spam Prediction

```bash

```

## 🚀 How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/your-username/Spam_Mail_Prediction.git
```

2. Navigate to the project directory

```bash
cd Spam_Mail_Prediction
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the notebook or Python script to train and test the model.
